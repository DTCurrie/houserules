# eval-fixture-repo

A tiny ESM time helper package.

Project token: HR-EVAL-TOKEN-4417

Run the tests with `npm test` and the linter with `npm run lint`. `npm run lint:fix` fixes what
the linter can fix on its own. Each module lives in its own directory under `src/`, with its
tests in `test/`, and `src/index.js` is the package entry.
