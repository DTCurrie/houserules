# worker-ladder-multi-repo

A small ESM checkout package with no dependencies.

Run the tests with `npm test`. Source lives in `src/`, tests in `test/`.

Every amount of money is an integer number of cents. Do money arithmetic with the helpers in
`src/money.js`, never with floats and `Math.round`. `src/invoice-contract.js` holds the shapes
and rules the invoice code is built against.
